# SQL and NoSQL Database Practice

This repository contains basic practice programs for **SQL** and **MongoDB (NoSQL)** databases.

## Files

### 1. `EM Schema.sql`

Contains SQL queries demonstrating:

* Database and table creation
* Inserting employee data
* Self JOIN to find employees and their managers
* Basic `SELECT` queries

### 2. `CRUD_MongoDB.js`

Contains MongoDB queries demonstrating:

* Creating and inserting documents
* CRUD operations
* Filtering and sorting
* Updating and deleting documents
* Indexing
* Aggregation pipelines
* `$lookup` operations
